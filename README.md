# Homework Repository

This repository contains my homework assignments completed as Jupyter Notebooks (`.ipynb`) throughout the course.

## Requirements

The notebooks are written in Python and may require the following packages:

- Python 3.10+
- Jupyter Notebook or JupyterLab
- NumPy
- Pandas
- Matplotlib
- Seaborn
- SciPy
- scikit-learn

Install the dependencies with:

```bash
pip install numpy pandas matplotlib seaborn scipy scikit-learn jupyter
```

If an assignment requires additional libraries, they will be imported within the corresponding notebook.

## Running the Notebooks

1. Clone the repository:

```bash
git clone https://github.com/<your-username>/<repository-name>.git
cd <repository-name>
```

2. Launch Jupyter:

```bash
jupyter notebook
```

or

```bash
jupyter lab
```

3. Open the desired notebook and run the cells in order.

## Notes

- Each notebook is self-contained and can be executed independently unless otherwise noted.
- Outputs, figures, and analyses are included for reference.
- Some notebooks may require datasets that are provided in the repository or specified within the notebook.

## Purpose

This repository serves as a collection of coursework and homework assignments completed during the course. It documents my solutions, analyses, and experiments while learning the material.
